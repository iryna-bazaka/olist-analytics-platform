# Generated preview artifacts

These small files are generated from the Olist source data by the local preview adapter:

- `dashboard.html`: self-contained static dashboard preview;
- `metric_snapshot.json`: machine-readable KPI and dimension snapshot;
- `metric_snapshot.md`: quick human-readable KPI summary;
- `quality_report.json`: data-quality results, including surfaced source warnings.

They are included as review artifacts; raw source CSVs are not committed.
